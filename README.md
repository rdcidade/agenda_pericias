Título do projeto: **Modernização da Gestão de Perícias Médicas: Uma Proposta de Integração Tecnológica em Clínicas Credenciadas**

Objetivo do trabalho: **Desenvolver uma aplicação web para a gestão digital, utilizando ferramentas de Tecnologia da Informação para automatizar e otimizar os processos de atendimento de perícias médicas realizadas nas clínicas médicas, centralizando o registro de dados e facilitando a geração de relatórios de produtividade em relação aos atendimentos realizados.**

Ferramentas utilizadas:

**Front-end**

* HTML

* CSS

* JavaScript

* Bootstrap

**Back-end**

* Python

* Django

**Banco de dados**

* MySQL

**Framework**

* Django

**Hospedagem**

* PythonAnywhere
**API**

* Gmail API
